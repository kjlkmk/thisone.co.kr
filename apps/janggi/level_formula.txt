1. 스톡피쉬 난이도 결정의 2가지 핵심 변수 공식
--------------------------------------------------------------------------------
스톡피쉬 엔진은 매 수마다 아래 2개의 명령어를 조합하여 착수 수준을 결정합니다.
  - setoption name Skill Level value [0 ~ 20]
  - go depth [1 ~ 20]

(1) 수읽기 깊이 (Depth: 1 ~ 20)
  - AI가 몇 수 앞까지 내다볼지 결정합니다.
  - [중요 특징] 스톡피쉬는 Depth 1이나 2로 설정하더라도, 마지막 수에서 기물을 잡고
    되잡는 연속 교환(Quiescence Search, 정적 탐색)은 끝까지 계산합니다.
  - 따라서 Skill이 높은 상태(Skill 11 이상)에서는 Depth 2만 되어도 공짜 기물을
    거의 내주지 않으며 전술적 방어력이 매우 높습니다.

(2) 스킬 레벨 (Skill Level: 0 ~ 20) - 스톡피쉬 내부 실수 유발 공식
  - Skill Level = 20 일 때:
    엔진이 계산한 1순위 최선수(Best Move)만 100% 정확하게 둡니다.
  - Skill Level = 0 ~ 19 일 때:
    스톡피쉬 내부 공식: weakness(약점 계수) = 120 - (6 × Skill Level)
    엔진이 내부적으로 상위 4개의 후보수(MultiPV = 4)를 뽑은 뒤,
    약점 계수(weakness)만큼 점수에 랜덤 흔들림(노이즈)을 주어서
    1순위 최선수 대신 2~4순위 차선수나 실수(악수)를 섞어서 둡니다.

  * 체감 구간 요약:
    - Skill 0 ~ 5  : AI가 꽤 자주 빈틈을 보이고 실수를 함 (18급 ~ 8급 입문/초급 구간)
    - Skill 6 ~ 9  : 기본 수비는 하지만 중반 전투에서 허점이 나옴 (6급 ~ 1급 중/상급 구간)
    - Skill 10 ~ 13: 실수가 눈에 띄게 줄어들며 1단 이상 실력자에게 승부가 됨 (초단 ~ 4단)
    - Skill 14 ~ 19: 실수를 거의 하지 않고 수읽기 깊이(Depth)로 압박함 (5단 ~ 8단)
    - Skill 20     : 엔진 풀파워, 오직 Depth만으로 기량이 결정됨 (9단 ~ 장기신)

4. 실전 튜닝 팁 (카카오장기 비교 테스트 시)
--------------------------------------------------------------------------------
1) 특정 레벨이 갑자기 너무 세게 느껴질 때:
   - `depth`를 올리는 타이밍을 늦추고 `skill`을 1~2 낮춰보세요.
   - 특히 `depth`가 1 증가할 때(예: Depth 2 -> Depth 3), 같은 레벨의 `skill`은 이전 레벨보다
     오히려 2~3 정도 낮춰서 시작해야 체감 난이도가 계단식으로 부드럽게 이어집니다.
     (예: Lv.12가 Depth 2 / Skill 12 라면, Lv.13은 Depth 3 / Skill 9~10 으로 설정)

2) 초급 구간(Lv.1~Lv.7)을 더 쉽게 만들고 싶을 때:
   - `depth: 1` 구간을 Lv.1 ~ Lv.7까지 늘리고, `skill`을 `0, 1, 2, 3, 4, 5, 6`처럼
     1씩만 올리면 입문자가 훨씬 수월하게 연승할 수 있습니다.
